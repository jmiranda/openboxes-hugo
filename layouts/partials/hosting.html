Where should OpenBoxes run?

OpenBoxes is free and open source, so you choose where it runs. The real question is who looks after the server: your team, or ours. This page walks you through the three options and helps you pick one.

Self-hosted

Download OpenBoxes and install it on a server you manage: in your own data center, a local machine at a warehouse, or any cloud provider. You get full control, and full responsibility.

Need it to work through internet outages? We can set up on-premise servers that sync with a cloud server. Ask us about it.

Read the install guide

DigitalOcean

Deploy a server with OpenBoxes already installed, billed to your own DigitalOcean account. It's the fastest way to get your own instance, and you still run it after that.

You pay DigitalOcean directly. Cost depends on the server size you choose.
